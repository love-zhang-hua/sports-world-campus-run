# 运动路线助手 · Windows 1.7.0

Windows 10/11，64位。运行 SportsRoute-1.7.0-Setup.exe，按向导安装；桌面及开始菜单都有入口，在系统“已安装的应用”中可卸载。程序数据单独保存在 `%LOCALAPPDATA%\SportsRoute`。卸载保留该目录，避免丢失用户自己的路线与存档；不需要时可自行删除。

## 配速、步频、步幅

根据本次提供的截图，去重后13条记录、两位跑者。参考数据在 `reference-runs.csv/json`，没有姓名、手机号或用户ID。未显示的距离、爬升和功率保留为空，不能从配速反推为“实测距离”。

模型以配速为自变量，使用20秒/公里带宽的高斯局部加权平均得到参考步频，再以 `速度=步频÷60×步幅` 计算步幅，步数随时间积分。样本覆盖3:57–6:46/km；范围外只使用最近边界的参考步频。界面显示参考值，逐点速度变化会使整次平均值略有不同。

这是一组小样本的描述性适配，不是个人运动能力预测。截图没有逐秒传感器数据，不能据此恢复停顿、瞬时配速、疲劳或心率。两人快跑/慢跑步幅差异明显，合并结果不强制单调。截图中的平均步频和步幅经过取整，可能与距离和步数有小幅出入。

热量、功率继续根据账号体重、距离、时长估算；不把另一人的热量和功率直接套到当前用户。未提供体重时采用程序原有默认体重，应在使用时核对。

## 路线高程与累计爬升

默认开启“按路线地形地图计算海拔与爬升”。程序把实际生成路线的BD09坐标转换为WGS84，再沿路线按约30米间距抽样，长路线最多100点，查询Open Topo Data的SRTM30m高程。发送的内容只有采样坐标，不发送账号、密码、Token。使用公共服务，无需Key。

数据源和接口说明：
- https://www.opentopodata.org/
- https://www.opentopodata.org/api/

对距离轴采样高程做三点平滑和1米死区滤波，插值到轨迹点；累计爬升是该曲线的正增量之和。总计和每圈从同一份曲线派生。平地可以得到零爬升；不会为匹配截图的8–37米而加噪声或强制放大。相同路线重复绕圈仍按实际经过次数累积爬升。

这是约30米分辨率的地形估计，无法准确描述校园台阶、桥面、楼层或很小的坡度，不能保证与手机GPS或气压计的爬升值一致。数据缺失、请求失败、返回坐标不符时明确报错，不以随机高度或零值替代。

地形模式与手动海拔互斥。关闭地形模式后，单值海拔就是恒定海拔；区间海拔属于模拟曲线。离线dry-run只检查本地结构，不查询高程服务，也不能用于证明某路线的真实海拔。

## 平台范围

Windows版是本机桌面程序；Android系统模拟定位需要Android设备，电脑版本不能直接替代手机的模拟定位提供者。地图与第三方业务接口可用性仍受网络和服务端权限影响。

本次不附带真实账号、登录态、测试密码或AI密钥。不自动启动登录测试，不自动提交记录。默认关闭上游自动更新，避免把本版覆盖为另一分支。
