# Android 下载、安装与使用

**只下载并安装一个 APK 即可。** 当前安装包已经内置账号登录、手动验证码、校区/必经点读取、地图选路线、轨迹核心和虚拟定位服务，不需要另装 LocationSpoofer、原版 Sports-simulation、测试包、地图 App 或编程环境，也不需要填写高德 Key。账号接口和实时地图需要联网。

## 1. 下载哪个文件

**[点击下载 SportsRoute-1.7.1.apk](https://github.com/love-zhang-hua/sports-world-campus-run/releases/latest/download/SportsRoute-1.7.1.apk)**

- 文件：`SportsRoute-1.7.1.apk`，约 2.3 MiB。
- 手机要求：Android 8.0 或更新、ARM64 / arm64-v8a。不是适用所有架构的通用包；仅 32 位的手机和 x86 模拟器不支持。
- 安装后桌面名称是 **“运动路线助手”**；GitHub 项目名称是“运动世界校园跑”。
- 只需上述 `.apk`。`.ipa` 是 iPhone 文件，`Source code` / `.zip` 是源码，`SHA256SUMS.txt` 是校验文件，都不需要下载安装。

进入本仓库的 **Releases** 页面，展开 **Assets**，点击 `SportsRoute-1.7.1.apk`。网页打不开可能是网络访问问题，先确认浏览器能正常访问 GitHub。不要下载 Source code 作为手机安装包。

## 2. 在手机上安装

1. 用手机浏览器打开上方下载链接，下载完成后打开该 APK；也可在“文件管理 → 下载”中找到它。
2. 系统提示“禁止安装未知来源应用”时，只对当前用于打开 APK 的浏览器或文件管理器开启 **“允许来自此来源的应用”**，然后返回安装页。
3. 点击 **安装**，完成后打开桌面的 **运动路线助手**。

这一安装方式不需要电脑、Root、USB 调试、USB 安装权限，也不需要安装分包工具。系统的来源授权和安装确认需要由你在手机上完成，一个 APK 无法替代这些系统确认。

## 3. 登录并选择跑步路线

1. 在 **“运动世界 · 未登录”** 中填写自己的账号和密码，点击 **登录**。出现验证码时手动完成；等待登录结果。
2. 登录后等待校区和点位加载。存在多个校区时，选择需要的校区；需要重新获取时点击 **刷新**。
3. 点击 **打开实时地图选路线**。主界面的小地图与这个实时地图入口不同，实时地图通过高德公开网页加载。
4. 拖动地图、双指缩放，沿道路按顺序轻点添加途经点。至少选择两个点；红色为必经点，橙色为普通点。选错时点击 **撤销**，完成后点击 **使用路线**。
5. 在 **跑步路线** 中设置速度。下方显示对应的配速、参考步频及步幅；参考来自跑步论文的群体模型，适用速度1.64–4.68m/s（约3:34–10:10/km），超出范围显示提示并使用边界步频估计。需要绕圈时勾选 **闭合路线，循环跑步**，再设置圈数；检查总里程和预计时间。

路线点之间是直线连接，不会自动沿道路寻路，转弯处应多加途经点。校区边界和必经点来自登录账号；底图是高德公开地图页面，不是运动世界官方应用的地图窗口。

## 4. 检查与提交选定路线

1. 在 **生成与提交** 填写路线所在城市，例如“徐州市”，选择 **校园跑** 或 **户外跑**。
2. 点击 **检查轨迹**，查看里程、时长、轨迹平均步频、步幅、步数及地形累计爬升。此步骤联网查询高程，但不会提交记录或要求账号登录。
3. 确认后点击 **提交路线**，再次核对弹窗内容并确认。等待服务端返回结果；不要连续重复点击。

时间段、账号状态或平台验证要求可能阻止提交，请按实际错误提示处理。只有地图上的点位或本地回放完成，不代表服务端已接受跑步记录。

## 5. 如果需要本机虚拟定位回放

“虚拟定位回放”和“提交路线”是两项独立功能。仅登录、查看点位和选择路线时，不需要先开启开发者选项。

1. 打开手机 **设置 → 关于手机**，找到 **版本号 / 软件版本号** 并连续点击约 7 次，按系统提示开启开发者模式；不同手机菜单名称可能不同。
2. 返回应用，展开 **虚拟定位回放 → 首次使用设置**，点击 **允许定位**。在系统提示中允许位置访问，并选择 **精确位置**；Android 13 及以上若提示通知权限，也允许通知。
3. 点击 **开发者选项**，找到 **选择模拟位置信息应用 / 模拟位置应用**，选择 **运动路线助手**。没有找到时可在手机设置中搜索“开发者选项”。
4. 返回应用，确认已选择路线和速度，点击回放区域的 **开始**；开始前先查询地形，失败会明确报错且不会开始回放。运行中显示海拔和累计爬升；可用 **暂停 / 继续** 和 **停止** 控制。
5. 如需切到后台继续，按手机系统需要允许应用后台活动；运行期间会显示定位服务通知。结束时点击 **停止**。

这里只需要开启开发者选项并选择模拟位置应用，**不需要打开 USB 调试或 USB 安装**。应用会在开始前检查定位权限和模拟位置设置；请按提示完成。无需同时运行其他模拟定位 App。

## 6. 退出与升级

- 使用完成：先停止虚拟定位回放，再展开账号栏，点击 **退出登录**，等待显示 **服务端已确认退出**。
- 退出失败时保留应用和会话，联网后重试。直接卸载或清空数据不能代替服务端退出。
- 升级：先停止回放并退出账号，再下载新版 APK，打开并选择 **更新**。同包名、同签名版本可覆盖安装，不需要多个安装包。
- 若提示“签名冲突 / 与现有应用冲突”，先确认旧版已完成服务端退出，再决定是否卸载旧版。自行编译的包通常使用不同签名，不能覆盖这里提供的版本。

## 常见问题

| 情况 | 处理 |
|---|---|
| 不知道下载哪个 | 只下载 `SportsRoute-1.7.1.apk`；不要下载 `.ipa`、源码 ZIP 或测试包。 |
| 安装后名称不是仓库名称 | 桌面显示“运动路线助手”，这是当前 APK 的正常名称。 |
| 提示不兼容、无法解析安装包 | 检查 Android 版本及 ARM64 支持；删除未下载完整的文件后重新下载，不要通过改扩展名安装。 |
| 系统限制安装来源 | 只给用于打开 APK 的浏览器或文件管理器授权，返回安装器继续；不需要更改 USB 设置。 |
| 只有点位，底图不完整 | 点击“打开实时地图选路线”；实时地图依赖网络和高德公开网页，不保证所有校区道路都存在。 |
| 实时地图加载失败 | 返回后重试，检查网络及系统 Android System WebView 是否可正常使用；页面结构或服务变化也可能导致失败。 |
| 开始回放时提示权限或模拟位置设置 | 按第 5 节设置精确定位，并选择“运动路线助手”为模拟位置应用。 |
| 登录、点位或提交报错 | 记录提示文字；可反馈错误，但不要公开账号、密码、验证码结果或会话文件。 |

## 7. 地形和运动参数说明

检查、回放和提交均从实际路线采样高程，采样坐标转换为WGS84后发送至Open Topo Data的SRTM30m服务；不发送账号、密码或Token，无需Key。经平滑后计算正向高度变化，绕圈按实际次数累计。约30米的地形分辨率不能可靠表达台阶、桥面或楼层，也不等同于手机气压计读数。缺失或请求失败时不补随机高度。数据源：https://www.opentopodata.org/api/ 。

步频来自论文群体模型，不是个人最优值；13条摘要保留为两位跑者的独立观测，不作为13名受试者混合拟合。步幅由实际速度和步频推导。详见[论文与数据审查](MODEL_EVIDENCE.md)。步频、步数属于本程序生成轨迹的参数，不改写手机硬件计步器。热量、功率仍按原模型估算，不照搬他人的数值。
